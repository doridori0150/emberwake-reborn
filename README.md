# Emberwake Reborn — 잿불의 귀환 (v0.1.0)

망한 길드를 되살리는 **단독 모험가 미궁 탐사 덱빌딩**. 오프라인 싱글 플레이 웹 게임(HTML + Canvas, 외부 라이브러리·네트워크 없음).

> 길드에서 투자 목표를 정한다 → 대원·덱·장비·목적지를 준비한다 → 미궁에서 탐사·전투·채집한다 → **더 들어갈지 지금 돌아갈지** 정한다 → 귀환문을 지나야 전리품이 남는다 → 시설·장비·카드·대원에 투자한다 → 길드와 다음 원정이 달라진다.

참조 프로젝트 `../EmberwakePrototype`(v0.16.1)와는 **폴더·앱 ID·IndexedDB·포트가 모두 다르다.** 원본의 게임·저장·배포물은 읽기만 했고 수정하지 않았다.

| 항목 | 값 |
| --- | --- |
| 앱 ID / DB | `emberwake-reborn` / IndexedDB `emberwake-reborn-db` |
| 개발 서버 | `http://127.0.0.1:8812/` (원본은 8791) |
| 포터블 빌드 | `dist/EmberwakeReborn-Portable.html` (단일 파일, 약 7.6MB) |

| 웹 게시본 | https://claude.ai/artifact/JtDzd9h3Wo5PMyG6u8oFtt (기본 비공개, 페이지의 공유 메뉴에서 공개 범위 설정). `npm run build`가 만드는 `dist/EmberwakeReborn-Artifact.html`을 다시 게시해 갱신한다. 게시본에서는 파일 내려받기가 막혀 저장 이동은 **저장 관리 → 텍스트로 복사·붙여넣기**를 쓴다 |

## 실행

```bash
npm start          # http://127.0.0.1:8812/  (node tools/server.cjs, 의존성 설치 불필요)
npm test           # 규칙·생성·경제·저장 자동 검사 28개
npm run build      # dist/EmberwakeReborn-Portable.html 생성
npm run sim -- verdant ara 200 loot   # 봇 원정 통계(난이도 근사치)
node tools/smart-bot.cjs 100 [grown]   # 대원별 스타일 전투 봇: 장면별 승률·잔여 HP(균형 방향 확인용)
npm run assets     # 참조 프로젝트에서 에셋 다시 가져오기 + 매니페스트 재생성
```

포터블 HTML은 Edge/Chrome에서 바로 열면 된다. `file://`에서는 브라우저 정책에 따라 IndexedDB가 막힐 수 있으며, 그때는 localStorage로 자동 대체된다(저장 관리 창에 표시). 주소·브라우저를 옮길 때는 **저장 관리 → 파일로 내보내기/가져오기**를 쓴다.

## 핵심 규칙 요약 (자세한 내용은 [docs/DESIGN.md](docs/DESIGN.md))

- **턴 = 이동력 + 주 행동 1 + 보조 행동 1.** 카드는 주/보조 중 하나를 쓴다. 카드가 없어도 기본 이동·공격·방어는 항상 가능하다.
- 내가 턴을 끝내야 적이 움직인다. 탐사 중 이동은 시간이 들지 않고, 시간은 방 이동(2)·채집(1)·상자(1/안전 3)·카드(1)·휴식(4)·전투 라운드(1)에만 흐른다.
- **붉은달 게이지**: 50% 술렁임(적 감지 +1, 처음 가는 방에 적 +1) → 80% 붉은달(시야 감소, 적 피해 +1, 달빛 결정 출현) → 100% 추적자 등장. 귀환문은 끝까지 열려 있다.
- 적은 **예고**한다: 사수는 조준 후 발사(시야 차단·근접 타격·제어로 풀림), 철갑병·수호자는 위험 칸을 한 턴 전에 표시. 한 적 턴에 실제 공격은 최대 2회, 원거리는 1회.
- 덱 12장·같은 카드 2장·시작 손패 5·턴당 2장·손패 한도 7. 덱이 돌 때마다 시간 +1.
- 주사위는 **일부 특수 카드와 상자·제단 판정에만** 쓴다. 굴리기 전에 비용·성공률·실패 결과를 보여주고, 실패해도 기본 보상은 받는다.
- 가방은 재료별 묶음 칸(기본 6칸). 넘치는 물품은 그 자리에 남는다. **귀환해야 창고에 들어가고 패배하면 가방을 잃는다.** 복구한 길드는 남는다.
- **발견 카드**: 위험 보물고의 금고와 봉인 상자 판정 성공 시 임시 카드 3장 중 1장을 그 원정 동안만 덱에 넣는다. 마음에 들면 귀환 후 연구해 영구화한다.
- 수호자는 예고 공격 외에, 다가와 곁에 닿으면 짧게 후려치고 4칸 넘게 달아나면 격노해 더 빨리 쫓는다.
- 수호자를 쓰러뜨리고 귀환하면 **추가 조건 없이** 다음 지역이 열린다. 전투를 피하려면 의뢰 게시판의 우회 항로(이전 지역 재료만 요구)를 복구한다.

## 현재 범위

미궁 3개(7·9·11방), 대원 3명(방어/반격 · 이동/밀치기/지형 · 상태이상/연쇄), 카드 34종(주사위 카드·판정 보조 포함), 적 14종(일반·정예·수호자 3·추적자), 시설 4종×3단계, 장비 10종, 의뢰 7개, 자동 저장·백업·내보내기/가져오기·손상 감지·탭 충돌 감지.

## 에셋과 교체 방법

그림은 모두 참조 프로젝트의 실행용 WebP를 **복사**한 것이다(원 출처: 참조 프로젝트 `CREDITS.md`·`ASSET-PIPELINE.md` — 내장 imagegen으로 만든 독자 디자인). 이번 작업에서 **새로 생성한 이미지는 없다.**

- 코드와 저장은 파일 경로가 아니라 의미 기반 ID(`actor.ara`, `enemy.warden`, `tiles.labyrinth`, `material.ore`, `facility.workshop.1`, `cardart.fire` …)만 쓴다.
- 교체: `assets/`의 파일을 바꾸거나 `tools/import-assets.cjs`의 매핑을 고친 뒤 `npm run assets` → `npm run build`. 캐릭터는 프레임별 `[x, y, w, h, pivotX, pivotY]`와 `bodyHeight`(발 기준점·몸 높이)로 배치되므로 원본 크기가 달라도 타일 크기는 변하지 않는다.
- 임시/부족 에셋 목록은 [docs/WORKLOG.md](docs/WORKLOG.md)의 "에셋 현황"에 있다.
