## 남은 결함·위험

- 난이도: 회랑 일반전은 아라에게 쉽다. 수문장은 2차 개선 R1에서 노아로 다시 플레이해 확인했지만(5턴까지), 아라·루미와 2·3지역 수호자는 봇 수치뿐이다.
- 적 걷기 애니메이션은 1프레임+들썩임, 적은 좌우 2방향뿐(원화 한계). 2·3지역 적은 1지역 스프라이트의 색조 변형이다.
- 길드는 클릭 방식이고 대원을 직접 걸려 다니지 않는다. 가구 배치·마을 확장은 없다(브리프가 후순위로 허용).
- 포터블 HTML은 개발 서버 경로로 띄워 확인했다(같은 출처라 저장이 공유됨).
